# User guide

Screening, summarization, typing, and custom databases.

<div class="grid cards" markdown>

-   **Screening contigs**

    ---

    Run `gapit screen` on FASTA, GenBank, and EMBL inputs with abricate-compatible
    thresholds and output formats.

    [Screening contigs](../screen.md)

-   **Screening reads**

    ---

    FASTQ and assembly FASTA through minimap2: paired input, presets, breadth-based
    presence, and two-stage surveys.

    [Screening reads](../reads.md)

-   **Summarizing reports**

    ---

    Turn one or more report tables into a gene presence/absence matrix.

    [Summarizing reports](../summary.md)

-   **Outputs**

    ---

    TSV, JSON, and Markdown contracts, versioned schemas, error envelopes, and exit
    codes.

    [Outputs](../outputs.md)

-   **Custom databases**

    ---

    Build a screenable database from any FASTA, GBK, or GFF file.

    [Custom databases](../custom-db.md)

-   **Typing schemes**

    ---

    Two-stage designation with `gapit typing`: rule and scheme primitives,
    worked examples, and calibration.

    [Typing schemes](../typing.md)

-   **Meningococcal serogroup typing**

    ---

    The `nme_sero` panel: serogroup plus `ctrA` and a single-copy `sodC` depth
    control.

    [Meningococcal serogroup typing](../nme_sero.md)
